# WindowsTopBar 中央功能入口

首期设计已实现。中央入口显示使用状态并提供手动休息操作。

## 已确定需求

- 将使用提醒圆圈移到主屏幕水平中点，作为 WindowsTopBar 自身小工具的常驻入口。顶栏保持 28 DIP。左侧快速启动与右侧应用提醒、系统状态各自保留空间，图标数量变化时中央按钮位置固定。
- 左键打开统一菜单。菜单显示本轮使用时长和「开始休息」。主题、亚克力、使用提醒开关及配置目录从顶栏空白处的右键菜单访问。
- 开启提醒时，悬浮提示显示本轮时长或休息状态。达到提醒阈值时沿用「本轮已使用 67 分钟，建议适当活动」一类文案。关闭提醒时，中央按钮仍可打开菜单，悬浮提示显示「WindowsTopBar」。
- 「开始休息」沿用现有流程。5 秒缓冲用于防误触，缓冲结束后的键鼠活动开启新一轮计时。关闭提醒结束当前计时，再开启时从零开始。

### 图标状态

60 和 90 分钟为默认阈值，继续读取现有配置。

| 状态 | 图标 |
| --- | --- |
| 不满 60 分钟 | 主题前景色空心圆 |
| 60 分钟至不足 90 分钟 | 主题前景色半实心圆 |
| 90 分钟及以上 | 实心圆，可用柔和的琥珀色 |
| 手动休息中 | 暂停标记 |
| 使用提醒关闭 | 固定的主题前景色空心圆 |

## 首期实现范围

- 在顶栏布局中独立定位中央按钮。以显示器边界计算中点，并按当前 DPI 换算到窗口坐标。AppBar 获得的窗口范围可能和显示器范围不同。 [顶栏布局](../../src/WindowsTopBar/MainWindow.xaml) · [AppBar 定位](../../src/WindowsTopBar/AppBar.cs)
- 菜单在按钮下方展开，显示使用状态和可用时的「开始休息」。休息中或提醒关闭时，菜单只显示对应状态。 [菜单逻辑](../../src/WindowsTopBar/MainWindow.xaml.cs)
- 复用现有计时、锁屏、熄屏和睡眠处理。继续利用现有 2 秒状态刷新更新图标，菜单和悬浮提示按需读取时长。 [计时状态](../../src/WindowsTopBar/UsageReminder.cs) · [系统事件](../../src/WindowsTopBar/UsageSystemEvents.cs)
- 窄屏或高缩放下，优先为中央入口和两侧常驻区域留出空间。应用图区从右向左显示放得下的完整图标，超出空间的图标及其提醒暂时不可见。 [应用区布局](../../src/WindowsTopBar/AppStatusPanel.cs)
